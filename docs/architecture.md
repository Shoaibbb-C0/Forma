# Architecture

Server-rendered React through Vinext on Cloudflare Workers. Shared layout and editorial components; client islands for navigation and forms. D1 prepared statements for content, enquiries and atomic rate limits, Drizzle schema migrations. Dispatch-owned ChatGPT authentication plus explicit editor email allowlist; fail closed if absent. Sites owner-only development hosting. No app passwords. CMS updates are same-origin POST requests. Reference photography is credited and clearly distinguished from concept design work.
