# Forma brand kit

## Identity

**Name:** Forma  
**Tagline:** Spaces with staying power.  
**Voice:** Measured, human, precise and optimistic. Use short, concrete language.

## Palette

- Paper / 60% — `#F5F5F5`
- Slate / 30% — `#56635D`
- Ink / 10% — `#111311`

## Typography

- Display: Playfair Display (Google Fonts), with italic used as an occasional counterpoint.
- Interface/body: Manrope (Google Fonts).
- Labels: DM Mono (Google Fonts).

## Logo usage

The wordmark is rendered as `FORMA®` in Manrope with tight tracking. Use Ink on Paper or Paper on Moss only. Keep it quiet; it should not become a decorative graphic.
